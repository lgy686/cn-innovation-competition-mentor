# 项目证据矩阵

将每个可复用主张映射为“主张—来源—事实等级—状态词—可用位置—备注”：

| 等级 | 含义 | 表述规则 |
|---|---|---|
| A | 直接佐证可核验 | 可作为已取得成果，注明来源 |
| B | 项目文件明确写出但暂未找到直接佐证 | 可作为待核实项目陈述，避免绝对化 |
| C | 基于材料的合理推论 | 只能写成分析、判断或建议 |
| D | 外部公开资料 | 必须写来源、发布日期/数据年份和链接 |

重点交叉核验专利数量和状态、合同/客户数量、收入与利润、用户和应用数量、技术性能、获奖情况、项目名称、商业模式、团队身份和时间口径。发现 A/B 或不同文件之间冲突时，列出文件、页码、数值和直接证据，停止把冲突数字用于定稿。
